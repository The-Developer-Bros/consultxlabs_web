## Non-negotiables

No generic outbox table exists in this repo; the domain rows already carry every pending obligation, and an idempotent sweep re-drives whatever a crashed `after()` callback missed. Every scheduled job has an HTTP twin gated by `CRON_SECRET` and wrapped in the same `withCronLock` its GitHub Actions entrypoint uses, so any scheduler that can POST can drive the fleet — this is what makes the five-minute Netlify ticker possible without a new table or a broker. A deploy preview, not a local dev server, is the only place that reproduces the `PG_POOL_MAX=1` single-connection deadlock, because a local pool has more than one connection. Full detail and sources live in the references above.
