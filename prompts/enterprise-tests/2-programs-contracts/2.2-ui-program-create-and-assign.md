## Case UI.PR.1: Create LICENSED_SEAT via wizard

Login as Wipro OWNER. Navigate to `/dashboard/organization/<wipro-id>/programs`.

`take_snapshot`. Click "Create program."

Wizard steps:
1. Select type → LICENSED_SEAT
2. Contract dropdown → ACTIVE contract
3. Name, coveredPlanTypes
4. Rate, cycle, cap, overageBehavior
5. Review → Submit

`wait_for("Program created")`.

### Assertions
- Program row in DB.
- UI table refreshes to show the new program.

## Case UI.PR.2: Assign learner

Click the new program → assignment tab. Click "Assign member" → pick a
LEARNER → set period. Submit.

```sql
SELECT "membershipId", "periodStart", "periodEnd" FROM "ProgramAssignment"
WHERE "programId" = '<programId>' ORDER BY "createdAt" DESC LIMIT 1;
```
Assert the assignment row.
